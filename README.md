# AI 校園導覽影片｜互動式教師研習簡報

這是一份可直接在瀏覽器操作的 11 頁教師研習簡報，主題為「AI 讓校園開口說故事：從照片到虛擬主持人導覽影片」。

## 功能

- 逐頁投影片導覽與全螢幕簡報模式
- 角色、三視圖、海報與影片提示詞一鍵複製
- 8 秒旁白字數檢查與瀏覽器語音試聽
- 素材隱私、影片品質與成果檢核表
- 學校、講師與日期個人化設定
- 自動在瀏覽器儲存勾選進度與行動計畫
- 支援手機、平板與電腦操作

## 本機開啟

直接以瀏覽器開啟 `index.html`，或在此資料夾啟動靜態伺服器：

```bash
python3 -m http.server 8000
```

接著開啟 `http://localhost:8000/`。

## 隱私提醒

請勿上傳學生個資、家長聯絡資料、帳號密碼、未公開研究資料或未經授權的學生臉部影像到 AI 服務。
